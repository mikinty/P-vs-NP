In spring 2011, Angela Weiss established P=NP by presenting a polynomial-time algorithm for
the 3-satisfiability problem.
The approach uses classical KE-tableaux methods to built a macro that stores the relevant
data (all closed branches) for a tableau for a given 3-sat formula.

The paper *"A Polynomial Algorithm for 3-sat"* is available from
[http://www.ime.usp.br/~weiss/](http://www.ime.usp.br/~weiss/).
This page also contains a discussion group on that proof.
