In June 2009, Arto Annila proved that P is not equal to NP.
He writes:
*The state space of a non-deterministic finite automaton is evolving due to the
computation itself hence it cannot be efficiently contracted using a deterministic
finite automaton that will arrive at a solution in super-polynomial time.
The solution of the NP problem itself is verifiable in polynomial time (P) because
the corresponding state is stationary. Likewise the class P set of states does not
depend on computational history hence it can be efficiently contracted to the
accepting state by a deterministic sequence of dissipative transformations.
Thus it is concluded that the class P set of states is inherently smaller than
the set of class NP. *

Annila's paper *"Physical portrayal of computational complexity"*
is available at
[http://arxiv.org/abs/0906.1084](http://arxiv.org/abs/0906.1084).
The paper has also been published in the journal *ISRN Computational Mathematics* 2012 ID: 321372, 1-15,
and is available at
[http://www.isrn.com/journals/cm/2012/321372/](http://www.isrn.com/journals/cm/2012/321372/).
