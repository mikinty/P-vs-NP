In June 2008, Bhupinder Singh Anand proved that P is not equal to NP
([pdf-file](http://alixcomsi.com/18_A_trivial_solution_to_PvNP.pdf)).
In this paper *"A trivial solution to the PvNP problem"* Anand shows that
Goedel has defined an arithmetical tautology R(n) which - when treated as a
Boolean function - is constructively computable as true for any given natural
number n, but which is not Turing-computable as true for any given natural number n.
This then implies that P is not equal to NP.
